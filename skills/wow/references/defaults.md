# 常见默认样本

给第 5 步的评审员用，帮它认出作品里残留的「千人一面」痕迹。这里只是样本，不是全集，也不是创作参考：做的时候不要照着它去「反着做」，那会变成另一种默认。

评审时发现新的默认，补进对应的类别；没有对应类别就新开一类。

- **网页**：奶油或米白底配衬线字加赤陶色点缀；近黑底配一个酸性绿；一排圆角卡片配同样的浅灰阴影；01/02/03 区块编号；等宽小标签；胶囊按钮；标题里的斜体强调词；紫色渐变；Inter 或 Roboto 字体（前五条见 Anthropic 官方 Opus 5.5 提示词指南）
- **面板、可视化**：深色底加霓虹蓝；世界地图飞线；环形仪表；数字滚动；全息扫描线
- **动画、短片**：渐变背景上居中的大标题；所有东西都在淡入；线性运动；硬切；结尾甩个 logo；粒子炸开；红黑配米白底（动效作品集那句提示词的通病）；字幕一律打字机逐字蹦出、末尾带闪烁光标（连中文字幕也跟着蹦）；词典词条排版给品牌或概念“下定义”（大号衬线单词 + 音标 + 词性 + 释义）；角落挂个假播放器时间码或 REC 标记来暗示“这是录像 / 在倒带”；物体旁拉细引线挂小号注释字（说明书式标注）来把比喻翻译成文字；整片锁死一个机位，转折全靠换字幕；字幕用遮罩从下往上推入，中文被切成半截；字幕条、画面大字、旁白三处说同一句话；开发工具片里的仿 macOS 终端窗口（红黄绿三点 + 黑底等宽字）；Excalidraw 式手绘圈、划线、下划线批注当万能强调；方格纸或工程绘图纸当底；结尾整体拉远露出整张画布（Prezi 式鸟瞰）；一整面墙相同缩略图比喻「千篇一律」；片尾「本片就是用 X 做的」自证收尾；讲解段退化成左对齐大标题 + 灰色小副标题 + 半屏留白的 Keynote 页；宣传工具的片子先放一版「烂的」再喊停、按工具的流程重做一遍来自证；用下棋（围棋、国际象棋）比喻人和 AI 协作，开场低机位一枚棋子落盘、上半屏一片黑；左上角常驻「● 章节名」面包屑代替画面交代段落；物体上贴红色问号气泡表示「这里被质疑」；落选方案用白边相片卡在主图下一字排开；宣传片照说明文档的章节逐段走，每段配一个比喻词；把功能全翻成比喻行话，观众得先学一套术语；用 A/B/C 圈加一张列表代表「几个方向」，方向本身的画面从不出现；主道具后半段闲着只当背景；「改前 / 改后」两版看上去一模一样；比喻自己立的规矩（如黑白分工）后面又被打破；冷开场先亮成品、再倒回第一步讲过程；3D 道具缓慢环绕、旁边浮一列要点字（带转台的 Keynote）；比喻里最关键的真实动作（钉、刻、缝、印）只在旁白里说，画面用替身道具代演；旁白从头铺到尾，画面只给旁白配字；问号气泡换个颜色仍是同一个默认
- **logo、图标**：首字母塞进圆圈；渐变球；抽象几何拼字母；灯泡、齿轮这类直白隐喻
- **海报、插画**：用一堆同样的现成小物件（瓶盖、纽扣、钉子、棋子）拼点阵字当巧思；赛博朋克霓虹；等距小人；扁平插画人物配大色块；过度对称的居中构图；AI 生图的「雨后古巷黄昏」（湿石板反光、暖光吊灯、斑驳白墙、盆栽加小板凳）当所有「烟火气」场景的万能背景
- **3D**：塑料质感；悬浮在渐变里的物体；过度辉光；处处景深；道具放在无边的暗色虚空里打一束光，地上投出生硬的大块阴影
- **中国题材**：水墨晕染；毛笔书法字；古筝、古琴配乐；宣纸纹理；红色印章；竹林；红底金字楷书招牌；温情例子默认选巷口老手艺小店（修鞋、裁缝、老面馆），配「老板几十年攒下的……」
- **命名**：-ify、-ly 结尾；Smart 或 AI 开头；拼音加「云」「智」「易」
