# wow

一句话想法，换来几条谁都想不到的路。

`/wow` 是一个头脑风暴 skill。你只给一句很短的想法，它先写出这个题目最普通、谁都会想到的做法，再想出 3–5 个绕开它、核心想法各不相同的方案，写成卡片交给你挑。设计、界面、可视化、动画、3D、产品概念、命名、文案、玩法都能用。

## 你会拿到什么

```
默认：<这个题目最普通的做法，具体到颜色、构图、比喻>

方案 1 · <名字>
  一句话：<这个方案是什么>
  关键画面：<第一眼看到什么>
  跟默认差在哪：<绕开了哪一点>

方案 2 · ……（共 3–5 个）

推荐：<押哪个，为什么>
```

- **方案之间真的不一样**：只差配色、排版、明暗或繁简的，算同一个方案。
- **你的想法不会丢**：你给的需求和限制照办；你给的想法会有一张卡片沿着它做透，其余的放开去想。
- **只出方案**：不做成品、不出图，几分钟就有结果，省时间也省额度。选定之后怎么做，由你决定。

## 安装

需要 Node.js 18+，用 [skills](https://github.com/vercel-labs/skills) 命令行工具安装。

**自己选装到哪些工具**（Claude Code、Codex、Cursor、Gemini CLI 等）：

```bash
npx skills add lijunyu726/wow-skill -g
```

运行后会列出支持的工具让你勾选。

**只装到 Claude Code**：

```bash
npx skills add lijunyu726/wow-skill -g -a claude-code
```

**直接指定几个工具**，名字之间用空格隔开：

```bash
npx skills add lijunyu726/wow-skill -g -a claude-code codex cursor
```

`-g` 装到用户目录，所有项目都能用；去掉 `-g` 则只装进当前项目。

## 使用

新开一个会话，输入 `/wow`，后面跟一句话：

```
/wow 给我的独立书店做个会员卡
```

description 里没有列触发词，主要靠手动输入 `/wow` 调用。

## 更新和卸载

安装时会从 GitHub 拉一份到本机，之后不会自动更新。要拿到新版：

```bash
npx skills update wow -g
```

卸载：

```bash
npx skills remove wow -g
```

## 目录

- `skills/wow/SKILL.md`：skill 本体，两步：认出默认、发散出方案卡片
- `docs/prompts.md`：Opus 5.5「一句话惊艳」案例的提示词写法总结（2026-10-24 整理）
- `docs/sources/`：每个来源的资料卡（概括、提示词结构、可复用做法、可信度提醒），防止原链接失效
  - `cn-official.md`：国内 6 个来源和 Anthropic 官方 3 份文档
  - `overseas.md`：海外 15 个来源

`docs/` 在 skill 目录外，调用时不会被读取。

## 边界

- 只是一份提示词，没有脚本或依赖。
- 不内置个人口味，也不规定风格。
- 尚未在真实题目上做过对比实测。
- 来源链接已于 2026-10-24 逐条打开核对，低质量来源已删除；资料卡是概括和短摘，完整原文以原链接为准。
