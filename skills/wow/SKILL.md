# 头脑风暴 · 你一句话，我全力以赴

用户的原意（多次原话合并）：

> 头脑风暴，抛弃刻板印象，大胆创新，做出一眼惊艳、让人觉得「还能这样做！」、看一眼就能记住、领先这个时代的东西。我只提供一点想法，不必照做；需求按我的来，过程和展现方式由你定，想法比我的好就用你的。全力以赴！

**核心认识**：网上那些「一句话做出惊艳作品」的案例，一句话只是表面，背后靠的是**简报、参照和自查**这一套流程。这个 skill 就是这套流程：用户只说一句，剩下九成由你补齐。

**适用范围很广，不限于网页。**下面每一步都按这次的媒介落地：

| 媒介 | 记忆点长什么样 | 成品形式 | 怎么亲眼检查 |
|---|---|---|---|
| 平面、品牌、logo、海报、图标 | 一个缩到很小也认得出的图形或构图 | 生成的图像，或 SVG / PDF | 出图后看大图和缩略图，黑白也能成立 |
| 界面、网页、面板、可视化 | 一个让人截图的画面或交互 | 可运行的单文件页面或原型 | 无头浏览器截图，手机宽度也截 |
| 动画、短片、动效 | 一个高潮镜头，加一个干净的收尾帧 | 代码渲染的视频或可播放页面 | 抽开头、高潮、结尾的帧来看 |
| 3D、生成艺术、插画 | 一个光影或形态上的「哇」 | 交互场景、图像序列 | 多角度截图，对照真实参照比质感 |
| 演示、课件 | 一页让人记住整场的画面 | 幻灯片或网页演示 | 逐页缩略图过一遍 |
| 产品、硬件、空间、活动概念 | 一个用户会讲给别人听的场景 | 概念图加一句话说明 | 换成第一次听到的人，能不能复述 |
| 命名、文案、玩法 | 一个念出来就记住的词或规则 | 候选清单加理由 | 大声念、搜重名、试着玩一局 |

## 0 · 不追问，自己拍板

用户要的是少说话、多惊喜。能查的自己查（代码、现有页面、真实数据、用户记忆里的偏好和硬规则），查不到的按最合理的假设定下来，写进交付物顶部「我替你定的」一栏，用户一眼能改。

用户连题目都没给（例如「做个让人惊叹的东西」）时，题目也由你来选，挑你最能做到极致的那个。开工后一路做完，中途不停下来请示，除非需要用户的账号、素材或付费。

只在两种情况下开口问：一是答案会让整件事南辕北辙（例如到底是给自己用的工具还是给别人看的展示品），二是会碰到用户记忆里的禁区。问也只问一轮，最多 2 个问题，每个都给选项和推荐。

## 1 · 自己写简报（200 字以内，每句都是一个决定）

一句话的想法会把所有决定都留空，模型就会拿最安全的默认值去填，结果就是「居中标题 + 渐变背景 + 淡入」。所以先替用户把简报写出来。

写简报时把自己当成一位设计总监：这个客户已经否掉了所有显得套路、模板化的提案。

- **给谁、干什么**：谁会看，最想让他们一眼看出什么
- **质量标杆**：点一个真实世界里的标杆来定「好」的高度，比如拿奖的网站、Apple 发布会片头、博物馆展陈、实物照片、某位大师的作品。短提示词能成，靠的是「放手 + 体裁 + 标杆」这三样，而不是堆形容词
- **情绪三个词**，再加一句「不是【最怕变成的那种套路】」
- **记忆点**：整件作品只押注一个让人倒吸一口气、愿意截图或转述的东西（画面、镜头、图形、词、规则），其余全部安静，给它让路
- **节奏**：动的东西只编排一个高潮，静的东西只留一个视觉焦点，不要处处都在用力
- **底线**：按媒介定。网页要手机能看、尊重减少动效设置；视频要每一帧单独拿出来都成立；logo 要缩小、黑白都成立；数据用真实的，或按真实特征生成。用到中文时点名字体（如苹方），不然渲染出来可能是方块；视频里的中文字号要足够大
- **禁用清单**（见第 2 步）

## 2 · 点名禁掉套路

光说「别像 AI 做的」没用，那只会把一种默认换成另一种默认。必须**点名**：

1. 先写出「这个题目 AI 最可能交的那一版」，具体到配色、字体、版式、动效。
2. 列出这类东西最常见的 5–10 个套路。例如：
   - **监控面板**：深色底加霓虹蓝、世界地图飞线、环形仪表、数字滚动、全息扫描线
   - **网页**：奶油底配衬线字加赤陶色点缀、近黑底配一个酸性绿、一排圆角卡片配同样的浅灰阴影、01/02/03 编号、等宽小标签、胶囊按钮、斜体强调词、紫色渐变、Inter 或 Roboto 字体
   - **动画、短片**：渐变背景上居中的大标题、所有东西都在淡入、线性运动、硬切、结尾甩个 logo、粒子炸开
   - **logo、图标**：首字母塞进圆圈、渐变球、抽象几何拼字母、灯泡加齿轮这类直白隐喻
   - **海报、插画**：赛博朋克霓虹、等距小人、扁平插画人物配大色块、过度对称的居中构图
   - **3D**：塑料质感、悬浮在渐变里的物体、过度辉光、处处景深
   - **命名**：-ify、-ly 结尾，Smart 或 AI 开头，拼音加「云」「智」「易」
3. 用户举的例子如果在清单里，当作要超越的起点，不当方向。
4. 第一版做出来又冒出新的默认样子，就把它也加进禁用清单。

## 3 · 发散，然后押注

**第一个冒出来的想法默认扔掉**：几百人发同一句话会得到几乎一样的作品，你的第一反应就是那个「一样的」。

发散 15–20 个一句话方向，至少用上 4 种换法：

- **换隐喻**：把它当成另一种东西（服务器 → 潮汐、来信、生态瓶、星盘）
- **换体裁**：借一个规则成熟的体裁，比如简历作品集、发布会片头、博物馆展签、天气预报、航海日志、电影片头字幕、邮票、说明书、地铁线路图
- **换媒介和物理感**：纸、墨、铜版、水面、玻璃、光影、声音、桌上的一块屏
- **换时间尺度**：此刻 / 一天 / 一年；直播 / 回放 / 日记
- **让真实数据长出形态**：形态由数据决定，不是给装饰贴上数据
- **反转约束**：最少的元素、没有文字、只有一个动作

为每个方向选一个**大胆而明确**的美学基调，比如极简到残酷、极繁、复古未来、编辑排版感、有机自然、工业、玩具感，不做两边都不得罪的中间态。

然后挑 3–5 个**方向差别最大**的，并**押注其中一个**：说清你为什么押它。大胆只花在一处，其余地方克制。

## 4 · 交付：画板加一个做到位的

默认交付分两样：

- **概念画板**（一个网页）：每个方向一张关键画面（真实渲染或生成的图，不是文字描述）、一句话核心、记忆点、为什么不是套路。成本低。
- **押注款**：押注的那个直接做成完整成品，形式按上面的媒介表来定，做到能拿出去给人看的程度。

用户说「全部做出来」「全力以赴」时，就全部做成完整成品。动手前报一下规模和预计耗时，因为用户的额度有限。

**停止条件按质量定，不按时长定**：「用满 6 小时」这类时间预算，实际会被提前交掉。要写成「评审团找不出明显差距为止」，或者「最多改 N 轮」。思考力度方面，长时间的创作用 xhigh 就够；max 不一定更好，还更慢、更贵。插画、图标等视觉素材按用户记忆里定的工具生成，不用代码硬画。

## 5 · 亲眼检查，再交

做完先自己看，不看不交。这一步是「一句话出惊艳作品」的真正关键，比任何加强语气都重要。

1. **建造者加评审员循环**：按媒介表里的方式出截图或帧，然后交给一个**新开的子代理**当评审员。它没看过你的过程，所以不会替你圆场。评审员把截图和质量标杆、真实参照并排比较，判断哪个更好，**点名最大的那一处差距**，退回给你改。至少两轮，直到它找不出明显差距，或者到了约定的轮数上限。截图交给子代理看，主会话只收文字结论，这样也省流量。
2. 拿截图对照第 2 步的禁用清单，命中一条就改。
3. 对照真实参照（照片、真实软件截图、实物）并排比质感：
   - 克制：降饱和、少发光、少描边
   - 光和材质按物理来：色调映射、边缘变暗、真实阴影，加极轻的颗粒防止色带
   - 数据要真，假数据最容易露馅
4. 按下面三条自评，不达标的继续改：
   - **一眼读懂**：3 秒内看出最重要的那件事
   - **记得住**：记忆点能用一句话复述，而且别处没见过
   - **有质感**：放在真实参照旁边不露怯
5. 达到这个媒介的底线：页面没有报错和掉帧，手机宽度下不乱；视频每一帧都成立；图形缩小和黑白都成立。

## 收反馈

- 用户说「不喜欢」但没给原因：给 3–4 个可能的原因让用户点选（太花 / 看不出重点 / 像游戏 / 质感廉价 / 和需求不符），按原因改，好的部分保留。
- 用户明说要「和之前无关的」才整批推翻；推翻时把上一批的教训写进禁用清单。
- 定下来的事（选了哪个、去掉哪些、硬性要求）写进项目文档或记忆，不只留在对话里。

## 口味档案

以下是从用户实际表态里总结的长期偏好，开工前先读；用户有新表态时更新这里。

- **喜欢**：写实、安静、克制，由真实数据驱动，比如夜半球。偏好「此刻」的真实感，光照、时间和访问都对应现实。
- **不要**：全息、霓虹、雷达扫描这类廉价科技感；黏土、玩具材质；塑料感；看不清的细节和发灰的淡字；刻意的署名或说明。
- **硬规则**：站名写子域名英文，页面禁止自动翻译。方案用网页画板展示，不用 ASCII 图。做图照真实资料，不凭印象编造。

## 交付前自检

1. 简报写了？禁用清单点名了？记忆点只有一个？
2. 3–5 个方向真的不同？押注款说清了理由？
3. 亲眼看过截图，对照过禁用清单和真实参照？
4. 规模没超出用户的额度预期？口味档案和用户记忆里的硬规则都守住了？
5. 交付最上面有「我替你定的」一栏？
6. 交之前照一照镜子，去掉一个可有可无的装饰。
